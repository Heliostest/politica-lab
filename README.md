# Politica lab

Public GitHub Pages demo for Historia **Part 2 · Politica** (political dynamics / five-resources population loop).

- Live: https://heliostest.github.io/politica-lab/
- Source game lab: `Heliostest/historia` (`demo-five-resources/` + `vite.five-resources-demo.config.mjs`)
- Formerly hosted as `five-resources-lab-demo`

Build (from a historia checkout):

```bash
npx vite build --config vite.five-resources-demo.config.mjs
```

Then commit and push the `outDir` contents to this repo's `master` (Pages source).
